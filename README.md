
# IoT-Based Wearable Remote Health Monitoring with Faint Detection System

## Project Overview
This academic project focuses on developing an IoT-based wearable system for remote health monitoring. It monitors health parameters such as heart rate, body temperature, and body movement using sensors integrated with an ESP32 microcontroller.

## Objectives
- Monitor heart rate and body temperature.
- Track body movement and orientation.
- Identify possible fainting events using programmed conditions.
- Transmit monitoring data through Wi-Fi.

## Hardware Components
- ESP32 Microcontroller
- MAX30102 Heart Rate and SpO2 Sensor
- MPU6050 Accelerometer and Gyroscope
- Temperature Sensor

## Technologies Used
- Embedded C
- Arduino IDE
- ESP32
- Internet of Things (IoT)
- Wi-Fi Communication

## Working Principle
1. MAX30102 collects pulse-related measurements.
2. MPU6050 tracks body movement and orientation.
3. Temperature sensor collects temperature readings.
4. ESP32 processes the sensor data.
5. Wi-Fi enables remote data transmission.
6. Programmed conditions are used to identify possible fainting events.

## Key Learning Outcomes
- Sensor integration with ESP32.
- Embedded system programming.
- Wi-Fi communication.
- Hardware testing and troubleshooting.
